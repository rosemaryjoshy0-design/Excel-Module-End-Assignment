# Excel-Module-End-Assignment

# Project Overview
This project processes, cleans, and analyzes a 2,335-record healthcare dataset across three tables (Customer Names, Medical Examinations, and Hospitalisation Details) to uncover clinical risk profiles, surgical distributions, and primary drivers of healthcare charges.

# Key Objectives
1. Data Cleaning
2. Data Transformation and Formulas
3. Data Visualisation
4. Interactive Dashboard
